What I Built

งาน Assignment 1 นี้ คือเว็บไซต์ Learning Portfolio แบบหน้าเดียว (Single-page Website) ที่รวบรวมข้อมูลส่วนตัว รายละเอียดการพัฒนางาน และการสะท้อนความคิดเกี่ยวกับการเรียนรู้ HTML/CSS

องค์ประกอบของเว็บไซต์

  • โครงสร้างใช้ Semantic HTML (<header>, <main>, <section>)
  • การจัดรูปแบบและวาง Layout ด้วย External CSS
  • การแทรกสื่อประกอบ (รูปภาพ ลิงก์ และรายการ)

การทำงานของ Client และ Server ขณะเปิดเว็บจากเครื่องตนเอง

ขณะที่เปิดไฟล์ index.html จากเครื่องตนเองผ่าน Browser (เช่น Double click ไฟล์ขึ้นมา) มีเพียง Client เท่านั้นที่เกิดขึ้น แต่ยังไม่มี Server เกิดขึ้น

เหตุผล: Web Browser ทำหน้าที่เป็น Client อ่านและแปลงไฟล์ .html และ .css ที่เก็บบน Disk ท้องถิ่น (Local File System ผ่านโปรโตคอล file:///) มาแสดงผลโดยตรง ไม่ได้มีการส่ง Request ไปยัง Web Server ผ่านเครือข่าย (HTTP/HTTPS Protocol) แต่อย่างใด

How I Built It

เขียนโค้ด HTML ตาม Semantic structure จากนั้นแยกเขียนไฟล์ CSS เพื่อตกแต่งความสวยงาม และทดสอบการแสดงผลบน Web Browser
